## 📌 1. Project Overview & Scope

The **Smart Exam Monitoring & Integrity Analytics Platform** is an independent, specialized Data Science module built exclusively for **Team 4**. It provides data ingestion, statistical telemetry analysis, behavioral pattern recognition, face monitoring error evaluation, multi-method outlier detection, transparent risk scoring, and automated report generation.

> [!IMPORTANT]
> **Independent Data Science Module:**
> Team 4 is an independent Data Science analytics dashboard. It integrates CSV telemetry received from the external exam-monitoring application (`Exam-monitoring-main`), validating, normalizing, and visualizing it without merging Flask and Streamlit or rewriting either core system.
>
> **Ethical AI & Human-in-the-Loop Principles:**
> This platform strictly adheres to fair proctoring standards. Suspicious behaviors are presented as **transparent analytical risk indicators requiring human supervisory review**. Candidates are **never** automatically accused or labeled as cheaters.
> 
> **Sprint 3 Face Monitoring Scope:**
> Evaluates detection accuracy and absence frequencies against labeled ground truth (`face_monitoring_ground_truth.csv`) and telemetry events. Does **not** build a live webcam or facial capture harness.

## 🚀 2. Exam-monitoring-main CSV Integration

Team 4 seamlessly ingests, harmonizes, and processes the large-scale CSV datasets generated by `Exam-monitoring-main`:

| Target Dataset | Source CSV Aliases | Key Schema Differences & Automated Harmonization |
| :--- | :--- | :--- |
| **Candidates** | `candidates_large.csv`, `candidates.csv` | Standardizes `candidate_id` across types; maps `department` to `candidate_group` for cohort analysis while retaining `name`, `roll_number`, `seat_number`, and `avatar_path`. |
| **Sessions** | `sessions_large.csv`, `sessions.csv` | Harmonizes `duration_mins` &rarr; `duration_seconds` (`* 60`) & `duration_minutes`; computes calculated `end_time = start_time + duration_mins`; repairs negative or corrupt durations. |
| **Events** | `events_large.csv`, `events.csv` | Maps `timestamp` &rarr; `event_time`; normalizes external event types (`normal` &rarr; `normal_activity`, `looking_away` &rarr; `focus_lost`, `left_seat` &rarr; `face_absent`, `talking` &rarr; `audio_detected`, `multiple_persons` &rarr; `multiple_faces`, `phone_detected` &rarr; `unauthorized_device`); assigns standard severity tiers (0, 1, 2); validates chronological bounds. |
| **Scores** | `scores_large.csv`, `scores.csv` | Validates `session_id`, `candidate_id`, and `integrity_score` (0–100 scale); retains `behavior_score` and `attention_score`. |
| **Risk** | `risk_data_large.csv`, `risk_data.csv`, `risk.csv` | Normalizes risk levels (`Moderate` &rarr; `Medium`, `Low`, `High`); retains `risk_id`, `risk_reason`, and `integrity_score`. |
| **AI Reports** | `ai_reports_large.csv`, `ai_reports.csv`, `ai_report_metadata.csv` | Maps `summary` &rarr; `notes` and `report_status = 'generated'`; retains `report_path`, `summary`, and `model_version`. |
| **Face Benchmark** | `face_monitoring_ground_truth.csv` | Maintained in `data/fallback/` as the verified ground-truth benchmark (298 samples, seed 42) for ML detection accuracy and confusion matrix evaluation. |

### Ingestion Pipeline Modes:
1. **External Source (Exam-monitoring-main):** Reads directly from `data/external` or configured directory.
2. **Fallback Baseline Data:** Automatic fallback to `data/fallback/` whenever external files are absent or uninitialized.
3. **Custom Directory Path:** Point to any directory containing external CSV files on disk.
4. **Live CSV File Uploader:** Drag-and-drop or select all 6 CSV files directly from the Streamlit sidebar.

## ⚡ 3. Performance Optimizations & Lag Fixes

To resolve previous dashboard latency when processing thousands of event records, the following optimizations were implemented:

1. **Vectorized Suspicious Pattern Detection (`src/suspicious_detection.py`):**
   - Replaced quadratic $O(N \times M)$ `iterrows()` session-event scanning with a single **vectorized `groupby` indicator matrix**.
   - Computes tab switches, face absences, focus losses, and composite flags using boolean masks.
   - **Performance benchmark:** Execution dropped from over 0.45s down to **0.034s** (over **12x speedup** on 3,747+ events).
2. **Vectorized Outlier Feature Extraction (`src/outlier_detection.py`):**
   - Replaced multiple iterative merges with a single-pass event type aggregation matrix.
3. **High-Performance Caching & Session State Synchronization:**
   - Decorated pipeline loading with `@st.cache_data(ttl=600)`.
   - Synchronized preprocessed DataFrames and audit metadata across `st.session_state` so switching between the 11 modules and 8 pages is instantaneous (0 ms recomputation).
4. **Responsive DOM Table Rendering:**
   - Implemented preview limiting (`.head(200)` with total record count badge and toggle) to prevent browser DOM freezing when rendering tables with thousands of rows.

## ⚡ 7. Quick Start Guide

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run Comprehensive Test Suite
```bash
python -m unittest discover tests -v
```
*(All 19 tests pass in < 1.0 second).*

### 3. Launch the Dashboard
```bash
streamlit run app.py
```
Open **`http://localhost:8501`** in your browser.

## 🛡️ 8. Ethical Principles

1. **Analytical Alerts Only:** Risk scores and flags are recommendations for human proctor review, never automated determinations.
2. **No Accusations:** Candidates are never labeled as cheaters.
3. **Objective Audits:** Transparent formulas, clear referential orphan accounting, and reproducible random seeds (seed 42) for all synthetic evaluations.
